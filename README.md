# OneClickServerMC

**マイクラ Java版で、MODを入れた「友達とのマルチプレイ」を、ほぼクリックだけで始められるWindows用ソフトです。**

- サーバーを立てる人（**鯖主**）：MODを選んで、ボタンを押していくだけでサーバーができます。
- 遊びに来る人（**友達**）：アドレスを貼って「遊ぶ」を押すだけで、同じMODが入ります。
- 鯖主がMODを変えると、友達のソフトに「更新があります」と出ます。

> このソフトは、Mojang / Microsoft とは関係のない、個人が作った**非公式ツール**です。

## 1. ダウンロードして起動する

**必要なもの**

- Windows のパソコン
- マイクラ Java版（正規版）
  - **公式ランチャーで、一度だけマイクラを起動しておいてください。**（はじめての人だけです）

**手順**

1. このページの **[Releases](../../releases)** を開きます。
2. いちばん上（最新版）の **`OneClickServerMC.zip`** をダウンロードします。
3. zip を**右クリック →「すべて展開」**で解凍します。
   - 解凍した**フォルダごと**、好きな場所に置いてください。
   - zip の中で直接開くと動きません。
4. フォルダの中の **`OneClickServerMC.exe`** をダブルクリックします。
   - Python などのインストールは**いりません**。

**最初に出る警告について**

「WindowsによってPCが保護されました」と出ることがあります。
知らない作者のソフトに出る、ふつうの警告です。

1. **「詳細情報」**を押します。
2. **「実行」**を押します。

> ウイルス対策ソフトが反応したときは、解凍したフォルダを「除外」に入れてください。

## 2. サーバーを作る（鯖主）

ここからは、**サーバーを立てる人**の手順です。
遊びに来るだけの人は、[4. サーバーに参加する](#4-サーバーに参加する友達)へ進んでください。

1. 左のメニューの **「新しいサーバーを作る」** を押します。
2. 画面の案内にそって、**マイクラのバージョン**と**サーバーの種類**を選びます。
   - よくわからないときは、**おすすめのまま**で大丈夫です。
3. **MOD**を入れます。
   - 「MOD」タブで、名前を検索して入れられます。
   - 目的別の「おすすめセット」を、まとめて入れることもできます。
4. 画面の右上の **「▶ 起動」** を押します。
   - 「起動完了」と出るまで待ちます。（MODが多いと数分かかります）
5. ホームの **「次にやること」** を、上から順に進めます。
   - ボタンを押していけば、友達を呼ぶところまで進みます。
   - **「ぜんぶ自動でやる」** を押すと、まとめて進めることもできます。

**ほかの作り方**

| 左メニュー | こんなとき |
| --- | --- |
| MODパックから作る | 配布されているMODパック（.mrpack）と同じサーバーを立てたい |
| 引っ越しファイルから作る | ほかのPCで作ったサーバーを、このPCに移したい |

**あなたも遊ぶとき（鯖主）**

1. サーバーを「▶ 起動」して、「起動完了」と出るまで待ちます。
2. **「友達」→「友達用パック」** を開き、**「自分のマイクラに入れる準備をする」** を押します。
3. 移った画面の青い **「入れる」** ボタンを押します。
4. 公式ランチャーを開き直し、**「サーバー名（マルチ用）」** を選んで **「プレイ」** を押します。
5. マイクラの「マルチプレイ」で、サーバーを選びます。
   - つながらないときは「ダイレクト接続」で `localhost` を入れてください。

## 3. 友達を呼ぶ（鯖主）

友達が入るには、次の3つが必要です。

### ① 外からつながる道をつくる

- ホームの上に、**「playit（外とつなぐ道）」** と **「友達が入れる状態」** の表示があります。
- 「playit」の **「▶ 起動」** を押すと、友達がつなげる**アドレス**ができます。
- 「友達が入れる状態」が**緑**になれば、準備OKです。
- 赤のときは、その横のボタンを押すと直せます。

### ② 友達の「マイクラの名前」を登録する

- **「友達」→「メンバー・BAN」** を開きます。
- **「入っていい人」** に、友達の**マイクラの名前**を入れて「追加」を押します。
  - **大文字・小文字も正確に**入れてください。
  - 登録していない人は、サーバーに入れません。（知らない人が入ってこないための、安全のしくみです）
- 登録を忘れても、入ろうとした人が **「入りたい人の申請」** に出ます。**「承認」**を押すだけで入れるようになります。

### ③ 友達に「招待」を渡す

- **「招待カードを作る」** を押すと、**アドレス・参加の手順・QRコード**が入った画像ができます。
- その画像を、LINE や Discord などで友達に送ってください。
- ファイルで渡したいときは、**「友達」→「友達用パック」** で **「パックを作る」** を押します。
  - **.mrpack** というファイルができます。これも友達に送れます。

## 4. サーバーに参加する（友達）

1. 公式ランチャーで、マイクラ Java版を**一度だけ起動**しておきます。（はじめての人だけです）
2. 鯖主に、**自分のマイクラの名前**を伝えます。
   - 登録されないと入れません。
3. [1. ダウンロードして起動する](#1-ダウンロードして起動する)の手順で、このソフトを起動します。
4. 左のメニューの **「友達のサーバーに参加」** を押します。
5. 鯖主からもらった**アドレス**（または招待リンク）を貼って、**「参加する」** を押します。
   - **.mrpack ファイル**をもらったときは、「ファイル（.mrpack）をもらった人はこちら」を開いて選びます。
6. 青い **「入れる」** ボタンを押します。
   - 同じMODが、あなたのマイクラに入ります。
   - ふだんのマイクラとは**別の場所**に入るので、混ざりません。
7. 公式ランチャーで **「（マルチ用）」** がついた起動構成を選び、**「プレイ」** を押します。
8. マイクラの **「マルチプレイ」** で、サーバーに接続します。

**2回目からは**、ソフトの **「▶ 遊ぶ」** を押すだけです。新しいMODがあれば、自動で入れてから起動します。

## 5. MODを変えたとき

### 鯖主

- MODを**追加・更新・削除**すると、約30秒後に、**友達用パックが自動で作り直されます**。
  - サーバーが止まっていても動きます。
  - 「友達」→「友達用パック」で、ON/OFFを切りかえられます。
- 「パックを作る」ボタンを押す必要は、ふつうはありません。

### 友達

- 「友達のサーバーに参加」に **「更新があります」** と出ます。（左メニューにも「更新1」と出ます）
- **何が変わったか**が見えます。
  - ＋ 追加
  - ↑ 更新（バージョンつき）
  - － 削除
- **「今すぐ更新」** を押すと、新しいMODが入ります。
- そのあと、いつもどおり **「▶ 遊ぶ」** を押してください。

## 6. 困ったとき

| こまりごと | まず試すこと |
| --- | --- |
| 友達がサーバーに入れない | **「メンバー・BAN」** に、友達の名前が**正確に**入っているか見てください。「友達が入れる状態」が緑かも確認します。 |
| サーバーが起動しない | 画面上の **「困ったとき診断」** を押してください。原因を日本語で教えます。 |
| 前のサーバーが残っていると出る | タスクマネージャーを開き、**java** を終了してから、もう一度「▶ 起動」を押します。 |
| 重い・カクカクする | **「設定」→「重さ・最適化」** で、原因を調べられます。メモリが足りないときは、そこで増やせます。 |
| 途中で落ちる | 画面に原因と直し方が出ます。メモリ不足のときは、自動で増やすこともできます。 |
| 更新のボタンが出ない | 鯖主のサーバーが起動していないと、友達はパックを確認できません。鯖主に起動してもらってください。 |

それでも直らないときは、`data\error.log` に記録が残っています。

## 7. 注意

- **大事なワールドは、先にバックアップをとってください。**
  - 「ワールド」→「バックアップ」で、いつでも作れます。
  - 起動の前に、自動でバックアップもとります。
- ソフトのフォルダの中の **`data` フォルダは、人に渡さないでください。**
  - 設定や鍵（Discord の通知用のURLなど）が入っています。
  - 友達に渡すときは、ソフトの設定の **「配布用の zip を作る」** で作った zip だけを渡してください。
- 使って起きたデータの消失などの責任は取れません。
- このソフトは、個人が作った**非公式ツール**です。
